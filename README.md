TikTok-Style Website Project 🎵

1. Project Description

My project is a TikTok-style website inspired by the popular social media platform TikTok. It allows users to share video content, write captions, like videos, comment on posts, and explore content shared by other users.

The website is built using HTML, CSS, and JavaScript in Visual Studio Code. GitHub is used to store the project files and publish the website online.

2. Who Is the Website For?

The website is designed for:

Students learning web development.

Content creators who want to share videos.

People who enjoy watching and interacting with videos.

Users who want to share ideas, creativity, and entertainment.

Beginners learning how social media websites work.

3. Main Features

Sign Up

Users can create an account by entering their name, username, and password.

Login

Registered users can log in using their username and password.

Video Feed

Users can view videos and read their captions in a scrolling-style feed.

Upload Videos

Logged-in users can select a video file from their device and add a caption.

Like Videos

Users can click the like button to increase the number of likes on a video.

Comments

Users can write comments and view comments left on videos.

Search

Users can search for videos by entering a username or caption.

Logout

Users can log out of their demo account.

Responsive Design

The website uses CSS to make its layout suitable for computers, tablets, and mobile devices.

4. Technologies Used

HTML: Creates the structure of the website, including forms, buttons, and the video feed.

CSS: Styles the website with colours, spacing, layouts, and responsive design.

JavaScript: Handles user interactions, signup, login, likes, comments, searching, and displaying posts.

Visual Studio Code: Used to write and edit the code.

GitHub: Stores the project files and supports version control.

GitHub Pages: Can be used to publish the front-end website online.

5. Explain the Data Part of the Website

The website works with user information and video post information. JavaScript collects information from forms, processes it, stores some of it in the browser, and displays it on the website.
